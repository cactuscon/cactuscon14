# PCB Files for the 2026 CactusCon Kids Badge
This directory contains all of the project files, gebers, BOMs, etc for the kids badge. The project is heavily built around production at JLC PCB and the colorful silkscreen files included in the gerbers will only work with JLC. On that note, the Gerbers have not been tested, our production order was directly through EasyEDA to JLC order.

- BOM_CCK14 Board_CCK14 Schematic_2026-02-15.csv: Bill of Materials, tied heavily to LCSC part numbers.
- Gerber_CCK14_PCB_2026-02-14.zip: Untested Gerber file produced from EasyEDA project.
- PCB_CCK14 PCB_2026-02-14.pdf: PCB images as a PDF
- ProPrj_CactusConKids14_2026-02-14.epro: EasyEDA project file containing schematics and PCB designs.
- SCH_CCK14 Schematic_2026-02-14.pdf: Electrical Schematics as a PDF
