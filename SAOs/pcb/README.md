# PCB Files for the 2026 CactusCon SAOs
This directory contains all of the project files, gebers, BOMs, etc for the SAOs we produced this year. The project is heavily built around production at JLC PCB and the colorful silkscreen files included in the gerbers will only work with JLC. On that note, the Gerbers have not been tested, our production order was directly through EasyEDA to JLC order. The ProPrj_CC14_SAOs_2026-02-16.epro is a local EasyEDA project save.

Note: For the hackachu SAO, any 5mm LEDs can be used and any 300 Ohm or greater resistors can be used.
